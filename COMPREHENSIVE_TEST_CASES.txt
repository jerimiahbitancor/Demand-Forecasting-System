3. DATABASE SCHEMA & TABLES
===================================

Core Tables:
- users: User accounts (auth_id, email, is_verified, etc.)
- email_verifications: OTP storage for registration
- password_resets: Password reset tokens
- business_profile: Business info (name, address, logo)

Product & Ingredient Tables:
- products: Menu items (name, price, category, status, dates)
- ingredients: Raw ingredients (name, unit, price)
- product_ingredients: Recipe mapping (quantity per serving)

Sales & Forecasting Tables:
- uploads: File upload history & status
- daily_sales: Historical sales data
- forecasts: Predicted quantities & revenue
- model_metrics: XGBoost accuracy (MAPE, MAE, RMSE)
- product_classifications: Demand tiers (High, Medium, Low, New, Discontinued)

Inventory & Stock Tables:
- ingredient_stock: Current stock levels & reorder thresholds
- stock_movements: Stock additions/consumption tracking
- market_price: Ingredient market prices from external sources

Operational Tables:
- notifications: In-app alerts & messages
- forecast_config: System configuration (safety buffer %)
- forecast_cogs: Cost of goods sold calculations
- system_actions_log: Audit trail
- fixed_holidays: Holiday dates to exclude from forecasts
- special_holidays: One-time special dates

4. API ENDPOINTS (HIGH-LEVEL OVERVIEW)
===================================

AUTH Routes (/api/auth/):
- POST /register - User registration
- POST /verify-otp - Verify OTP
- POST /create-password - Create auth user & password
- POST /resend-otp - Resend OTP
- POST /sync-user - Sync Supabase user to custom users table
- GET /setup - Check if user setup is complete
- POST /forgot-password/send-code - Send reset code
- POST /forgot-password/verify-code - Verify reset code
- POST /forgot-password/reset-password - Reset password

PRODUCT Routes (/api/mapping/):
- GET /products - List all products
- GET /products/:id - Get product with ingredients
- POST /products - Create product
- PUT /products/:id - Update product
- DELETE /products/:id - Delete product
- POST /products/:id/archive - Archive product
- POST /products/:id/reactivate - Reactivate product
- GET /categories - Get product categories
- GET /stats - Get product statistics
- GET /search - Search products

UPLOAD Routes (/api/upload/):
- POST / - Upload file (CSV/Excel)
- GET / - List uploads
- GET /:id - Get upload details
- PUT /:id - Update upload
- DELETE /:id - Delete upload
- GET /:id/status - Check upload status
- GET /stats/summary - Upload statistics

SETTINGS Routes (/api/settings/):
- GET /business-profile - Get business profile
- PUT /business-profile - Update business profile
- GET /forecast-config - Get forecast configuration
- PUT /forecast-config - Update configuration

NOTIFICATIONS Routes (/api/notifications/):
- GET / - Get user notifications
- POST /:id/read - Mark as read
- DELETE /:id - Delete notification

USERS Routes (/api/users/):
- GET / - List all users (admin)
- GET /:id - Get user details
- PUT /:id - Update user
- DELETE /:id - Delete user (admin)
