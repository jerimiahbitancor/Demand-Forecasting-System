10. Forecast Horizon Breakdown

This section is recursive — day N's prediction depends on day N-1's prediction, exactly as production forecasting does (forecast_service.generate_forecast()). Sections 5/6/9 above are single-step backtests (every row uses REAL actual lag/rolling values, never a prior prediction) and are NOT directly comparable to the numbers here.

Simulated for both representative products (product 425, high-volume; product 384, low-volume) across 8 (product, start date) combination(s) spread evenly across the test period. Each day's prediction is fed back in as the next day's lag_1 via build_forecast_feature_row() — the exact function generate_forecast() calls, not a reimplementation. Known actual values are used here only to SCORE the simulation after the fact — they are never fed into the simulation itself.

Simplification, stated explicitly: this simulation predicts every calendar day in the 7-day horizon and does not apply production's weekend/closed-day short-circuit (forecast_service._is_operating_day()) — the goal here is isolating pure model recursive-error growth by horizon day, not reproducing the business-day rule on top of it.
